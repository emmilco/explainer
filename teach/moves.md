# Move taxonomy

Typed outer layer, revisable inner layer (§7). One row per move type. Learner-specific
evidence lives in `profile/profile.md` (Move preferences); this file defines the types and
their known behavior. Revision protocol: a post-session state update may propose a new type or
a split when signals show hidden variance; accepted changes append a dated rationale to
Revision history. The table is never silently rewritten.
